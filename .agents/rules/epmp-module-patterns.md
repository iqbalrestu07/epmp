## EPMP Module Patterns

> Concrete, project-specific patterns for the Go backend and the React frontend.
> Universal principles (testability, error handling, logging) live in their own rule files; this file shows *how they are expressed in EPMP*.

### Architecture Context

- **Backend:** Go 1.26, Echo v4 (`github.com/labstack/echo/v4`), pgx/v5 (`pgxpool`), zerolog, golang-jwt v5, golang-migrate, whatsmeow. Module path `github.com/epmp/backend`.
- **Frontend:** React 18 + TypeScript, Vite, React Router v6, TanStack Query v5, React Hook Form + Zod, Tailwind, TanStack Table, Recharts, @react-three/fiber. Package manager **npm**.
- **Database:** PostgreSQL 16. UUID primary keys (`internal/pkg/uid`), soft delete via `deleted_at`, `organization_id` on every tenant-owned table.
- **Auth:** JWT Bearer token (`Authorization`) + active organization header `X-Organization-ID` (see @multi-tenancy-boundary.md).
- **Standards:** `epmp-docs/epmp-011.md` (Backend Architecture), `epmp-docs/epmp-010.md` (Engineering Platform), `tools/epmp-ai/RULES.md`, `tools/epmp-ai/CONVENTIONS.md`.

### Backend Rules

**1. Layering inside a module** (dependency direction: delivery → service → repository interface ← repository impl)

```go
// module.go — the only place that knows concrete implementations
func NewModule(db *pgxpool.Pool, log zerolog.Logger) *Module {
	var repo repository.PropertyRepository = repository.NewPropertyRepositoryImpl(db)
	svc := service.NewPropertyService(repo)
	handler := http.NewPropertyHandler(svc)
	log.Info().Str("module", "property").Msg("module initialized")
	return &Module{Handler: handler}
}

func (m *Module) RegisterRoutes(e *echo.Group) {
	g := e.Group("/properties")
	http.RegisterPropertyRoutes(g, m.Handler)
}
```

- Services depend on the **repository interface**, never on `*pgxpool.Pool`.
- Handlers depend on the service, never on the repository.
- Cross-module access goes through the other module's **service**, never its repository or tables (`tools/epmp-ai/RULES.md` MR-004).

**2. Handler shape** — bind → validate → resolve org → call service → map error → envelope

```go
func (h *PropertyHandler) Create(c echo.Context) error {
	var req dto.CreatePropertyRequest
	if err := c.Bind(&req); err != nil {
		return response.BadRequest(c, "invalid request body")
	}
	if req.Name == "" {
		return response.BadRequest(c, "name is required")
	}
	orgID := mw.GetOrgID(c)
	if orgID == "" {
		return response.BadRequest(c, "X-Organization-ID header is required")
	}
	result, err := h.svc.Create(c.Request().Context(), &req, orgID)
	if err != nil {
		if errs.IsDomainError(err, "NOT_FOUND") { return response.NotFound(c, "Property not found") }
		return response.InternalError(c, "failed to create property") // never leak err.Error() to clients
	}
	return response.Created(c, result)
}
```

**3. Response envelope** — always use `internal/pkg/response`; never `c.JSON` with ad-hoc shapes.

```json
{ "success": true,  "data": { ... } }
{ "success": false, "error": { "code": "NOT_FOUND", "message": "..." } }
```

List responses carry `{ data: [], total, page, per_page, total_pages }` inside `data`. Query params: `page`, `per_page`, `search`, `sort`, `order`.

**4. Errors** — business failures are `*errs.DomainError` (`errs.ErrNotFound`, `errs.ErrConflict`, `errs.ErrValidation`, or `errs.NewDomainError(code, msg)`). Wrap infrastructure errors with context: `fmt.Errorf("property service: create: %w", err)`. Handlers map codes with `errs.IsDomainError`.

**5. Repository** — org-scoped signatures (`FindByID(ctx, id, orgID)`), every query filters `deleted_at IS NULL`, parameterised SQL only (`$1, $2`), `Delete` is a soft delete (`SET deleted_at = now()`).

**6. Logging** — zerolog via `internal/pkg/logger.New()`; structured fields (`.Str("module", ...)`) not string formatting; never log tokens, passwords, or full request bodies.

**7. Route registration** — `modules.Register` in `internal/modules/modules.go` mounts `/api/v1`; protected modules go on the `protected` group (JWT + audit log). Adding a module = `NewModule(db, log).RegisterRoutes(protected)` there.

**8. Generated code** — files starting with `// Code generated by epmp-sdk. DO NOT EDIT.` come from `tools/epmp-sdk/be/codegen`. Prefer editing the YAML in `tools/epmp-sdk/schemas/` and regenerating. If a hand-edit is unavoidable, remove the header so future regeneration does not silently overwrite it.

### Frontend Rules

**1. Feature module layout** — `api/` (fetch functions) → `hooks/` (TanStack Query) → `pages/`/`components/`; `types/` and `schema/` shared across them. See @project-structure.md.

**2. API access** — only through `@/services/api` (`api.get/post/put/delete`). It injects `Authorization` and `X-Organization-ID` and throws `ApiError(status, message, data)`. Never call `fetch` directly from components.

```ts
const res = await api.get<{ success: boolean; data: Property }>(`${BASE_PATH}/${id}`);
return res.data;
```

**3. Server state** — TanStack Query hooks with a per-feature `QUERY_KEY`; mutations call `queryClient.invalidateQueries({ queryKey: [QUERY_KEY] })` on success. No manual `useEffect` fetching.

**4. Forms** — React Hook Form + `zodResolver` with schemas from `features/<x>/schema`. Zod schema field names mirror backend DTO JSON (`snake_case`).

**5. Routing** — every page is registered in `frontend/src/App.tsx` under `/dashboard/...`, wrapped by `ProtectedRoute`/`PermissionGuard` as appropriate, **and** added to `PAGES_TO_TEST` in `frontend/run_e2e_tests.cjs`.

**6. UI** — Tailwind + `components/ui/*` primitives (`button`, `card`, `input`, `label`, `SearchableSelect`, ...); `cn()` from `@/lib/utils` for class merging; Lucide icons. Currency/date formatting via `@/utils/currency` and `@/utils/date`.

**7. Generated code** — same rule as backend: `// Code generated by epmp-sdk. DO NOT EDIT.` files come from `tools/epmp-sdk/fe/codegen`.

### Testing Approach (what actually exists)

| Level | Backend | Frontend |
|---|---|---|
| Unit | `go test` on pure service/entity logic with a hand-written fake repository | none configured yet (no Vitest); keep logic in pure functions so it can be added |
| Integration | `<name>_api_test.go` using `internal/testutil` (`testutil.Setup`, `AssertCRUD`, `AssertUnauthorized`, fixture chains) against a real Postgres at `DATABASE_URL` (default `localhost:5432/epmp`); tests **skip** when DB is unreachable | — |
| E2E | — | Playwright via `make test-e2e` (system Chrome, `run_e2e_tests.cjs`), frontend `:3000` + backend `:8080` must be running |

New modules MUST ship a `<name>_api_test.go` covering CRUD + cross-org isolation (`testutil.AssertCRUD`).

### Local Workflow

```bash
cp .env.example .env
docker compose up -d postgres                 # Postgres 16 on :5432
cd backend && go run ./cmd/migrate up         # apply migrations
make dev-backend                              # Echo on :8080
make dev-frontend                             # Vite on :3000
make test-backend | make test-frontend | make test-e2e
```
